# One Word From Grandma

Entry for the make.fun bounty "One Word From Grandma". The program
(`main.py`, Python 3, standard library only) writes exactly one word to
`/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`): the single
word a grandma would text about AI.

**Final word: `ChatGTP`**

The joke is in the spelling: it is the transposed-letter typo of
ChatGPT that a grandma would actually make — she has heard the name
from her grandchild and is bravely typing it back, warm and a little
baffled. It is tied specifically to AI, instantly readable, and funny
in one word with no caption. The full candidate list (12 words) and
the two-pass reasoning — first pick "Cookies" (baking vs. browser
cookies), refined to "ChatGTP" under the judge's criteria order — are
documented in the docstring of `main.py`.
